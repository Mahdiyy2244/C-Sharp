Console.Write("Mahdi");
Console.ReadKey();
📘 What does this code do?
Console.Write("Mahdi"); and Console.WriteLine("Mahdiyy2244");  → Prints the name "Mahdi" to the terminal or console screen in the new line.

Console.ReadKey(); → Holds the program until the user presses a key and then closes (so we can see the output).
