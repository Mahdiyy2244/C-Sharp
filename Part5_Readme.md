# Simple C# Addition Calculator

A beginner-friendly C# console application that demonstrates basic variable declaration, arithmetic operations, and console input/output.

## 📌 About The Project

This project is a simple C# program that adds two integer numbers and displays the result in the console.

The program:

* Defines two integer variables (`num1` and `num2`)
* Calculates their sum
* Prints the result to the console
* Waits for user input before closing

## 🚀 Getting Started

### Prerequisites

To run this project, you need:

* [.NET SDK](https://dotnet.microsoft.com/download)
* A code editor such as Visual Studio or Visual Studio Code

### Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/your-repository-name.git
```

2. Navigate to the project folder:

```bash
cd your-repository-name
```

3. Run the application:

```bash
dotnet run
```

## 💻 Code Example

```csharp
int num1 = 2, num2 = 2;

Console.Write(num1 + num2);

Console.ReadKey();
```

## 📤 Output

```
4
```
