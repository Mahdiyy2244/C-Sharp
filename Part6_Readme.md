# 📐 Rectangle Area & Perimeter Calculator

## 📌 Overview

This is a simple **C# Console Application** that calculates the **area** and **perimeter** of a rectangle based on the length and width entered by the user.

The program prompts the user for the rectangle's dimensions, performs the necessary calculations, and displays the results in a clear format.

---

## ✨ Features

* Accepts rectangle **length** from the user.
* Accepts rectangle **width** from the user.
* Calculates:

  * ✅ Area
  * ✅ Perimeter
* Displays the results in the console.
* Beginner-friendly and easy to understand.

---

## 🧮 Formula Used

**Area**

```text
Area = Length × Width
```

**Perimeter**

```text
Perimeter = 2 × (Length + Width)
```

## ▶️ How to Run

1. Open the project in **Visual Studio**.
2. Build the project.
3. Run the application.
4. Enter:

   * Rectangle Length
   * Rectangle Width
5. View the calculated area and perimeter.
