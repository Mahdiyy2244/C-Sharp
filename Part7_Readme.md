# 🧮 C# Console Calculator

A simple and beginner-friendly **console calculator** built with **C#**.
The program allows users to enter two numbers and choose a mathematical operation to calculate the result.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔢 Supports decimal numbers
* 🖥️ Simple and easy-to-use console interface

## 🛠️ Built With

* **C#**
* **.NET**

## 🚀 Getting Started

### Prerequisites

To run this project, you need to have the **.NET SDK** installed on your computer.

You can check whether .NET is installed by running:

```bash
dotnet --version
```

### Installation

Clone the repository:

```bash
git clone https://github.com/Mahdiyy2244/C-Sharp.git
```

Navigate to the project directory:

```bash
cd C-Sharp
```

Run the application:

```bash
dotnet run
```

## 💻 Usage

After running the program, enter the requested values:

```text
Enter your First Number : 10
Enter your Secend Number : 5
Choise your operation from *,/,+,- : *
Result is 50
```

### Supported Operations

| Operator | Description    |       Example |
| :------: | -------------- | ------------: |
|    `+`   | Addition       | `10 + 5 = 15` |
|    `-`   | Subtraction    |  `10 - 5 = 5` |
|    `*`   | Multiplication | `10 * 5 = 50` |
|    `/`   | Division       |  `10 / 5 = 2` |
